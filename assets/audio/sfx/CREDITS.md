# Sound credits

These are placeholders. Swap them in the Sounds tool (`python tools\ai_asset_pipeline\run.py serve`)
whenever you like; the file name prefix shows where each one came from.

| Prefix | Events | Source | Licence |
| --- | --- | --- | --- |
| `kenney_*` | footstep_grass, footstep_asphalt (concrete), footstep_sand (snow), bullet_impact, bullet_hit | [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds) | CC0 |
| `tinyworlds_*` | footstep_dirt (mud), footstep_forest (leaves), footstep_gravel, footstep_rock (stone) | [OpenGameArt: Different steps on wood, stone, leaves, gravel and mud](https://opengameart.org/content/different-steps-on-wood-stone-leaves-gravel-and-mud) | CC0 |

| `firearm_*` | shot, shot_far | CC0 stock `gamespice-platform/audio` on GitHub (Kenney-derived) | CC0 |
| `sfxmint_*` | shot | [SFXMint](https://sfxmint.com), AI-generated | CC0 |
| `oga_boar_fvcalderan.ogg` | hog_grunt, hog_alert, hog_charge | OpenGameArt, fvcalderan | **confirm on the page before shipping** |
| `soundza_pig_grunt_and_squeal.mp3` | hog_grunt, hog_hurt, hog_die | Soundza | **confirm before shipping** |

The hog sounds are two recordings reused with different pitch ranges (alert is higher,
charge and death are lower), so they are the first thing worth replacing.
